# Changelog

## 1.0.0
- First release: 10 MCP tools (`ag_status`, `ag_diagnose`, `ag_send`, `ag_result`, `ag_tasks`, `ag_cancel`, `ag_read_screen`, `ag_buttons`, `ag_stop`, `ag_screenshot`).
- File mailbox with one-time completion codes, secret scrubbing, loopback-only debug port, Windows launcher with a local-only safety check.
- Default data folder is now `~/.agy-bridge/data` (server and launcher agree).
